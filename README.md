# User Dashboard

A simple team management dashboard built with Angular 17.

## Getting Started

Fire up the dev server with `ng serve` and head to `http://localhost:4200/`. Changes you make will reload automatically.

## Building for Production

Run `ng build` and you'll find everything in the `dist/` folder ready to deploy.

## Testing

Use `ng test` to run unit tests with Karma.

## Need Help?

Check out the [Angular CLI docs](https://angular.io/cli) or run `ng help` in your terminal.
